Claude Code website section package

Files included:
- section.html: section markup to paste into your page/component
- section.css: scoped component styles
- strings-effect.js: interaction engine
- init.js: startup script for the section
- IMPLEMENTATION.md: integration instructions

This package is prepared to be dropped into a website build as a reusable section.
Background: #F7F7F7
Interactive graphics: #1748DF
